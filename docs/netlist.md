# ネットリストと基板設計メモ（Rev.3）

EasyEDA などで回路図を起こし、PCB を設計するための資料。
接続は [docs/schematic/gamepad_wireless_schematic.svg](schematic/gamepad_wireless_schematic.svg) と同じ内容を表にしたもの。

## 1 枚の基板で送信機・受信機の両方をまかなえる

受信機は**送信機から USB-A まわり（J1・C1・R1・R2）を省いたもの**で、それ以外は完全に同じ。
1 種類の基板を作り、実装する部品を変えるだけで両方に使える。

| | 送信機 | 受信機 |
|---|---|---|
| U1 XIAO RP2040 | ● | ● |
| U2 IM920sL + ADP | ● | ● |
| C2 10µF / C3 0.1µF | ● | ● |
| J1 USB Type-A / C1 47µF / R1・R2 22Ω | ● | — |

## 部品

| RefDes | 部品 | フットプリント | 備考 |
|---|---|---|---|
| U1 | Seeed XIAO RP2040 | 2.54mm 7×2（幅 17.78mm） | ソケット実装を推奨（書込み・交換のため） |
| U2 | IM920sL + IM920sL-ADP | 2.54mm 10×2（J1/J2、間隔は ADP 外形図に従う） | ADP の外形 30.0 × 40.0mm、取付穴あり |
| J1 | USB Type-A レセプタクル（メス） | 基板直付け・横型（DS1095-WNR0 相当） | 送信機のみ |
| C1 | 電解コンデンサ 47µF 10V | φ5mm / 2.54mm ピッチ | 送信機のみ。J1 の近くに |
| C2 | 積セラ 10µF | 2.54mm ピッチ または 1206 | U2 の VCC 直近 |
| C3 | 積セラ 0.1µF | 2.54mm ピッチ または 0603/0805 | U2 の VCC 直近 |
| R1, R2 | 22Ω 1/4W | 2.54mm ピッチ または 0805 | 送信機のみ。D−/D+ の直列抵抗 |

XIAO RP2040 のピン配置（外形 17.5 × 20.5mm、2.54mm ピッチ 7×2）:

```
左側（上から）: D0/A0(GPIO26) D1/A1(GPIO27) D2/A2(GPIO28) D3/A3(GPIO29)
                D4/SDA(GPIO6) D5/SCL(GPIO7) D6/TX(GPIO0)
右側（上から）: 5V  GND  3V3  D10/MOSI(GPIO3)  D9/MISO(GPIO4)
                D8/SCK(GPIO2)  D7/RX(GPIO1)
```

IM920sL-ADP は `J1-n = 本体 pin(2n−1)`、`J2-n = 本体 pin(2n)`（製品資料 Rev.1.0 回路図で確認済み）。

## ネットリスト

| ネット | 接続先 |
|---|---|
| `+5V` | U1 5V — J1(USB-A) pin1 VBUS — C1 (+) |
| `+3V3` | U1 3V3 — U2 J1-9 (VCC, 本体 pin17) — C2 (+) — C3 |
| `GND` | U1 GND — U2 J2-9 (GND, 本体 pin18) — J1(USB-A) pin4 — C1 (−) — C2 (−) — C3 |
| `USB_DP` | U1 D0/A0 (GPIO26) — R2 — J1(USB-A) pin3 (D+) |
| `USB_DM` | U1 D1/A1 (GPIO27) — R1 — J1(USB-A) pin2 (D−) |
| `IM_BUSY` | U1 D2/A2 (GPIO28) — U2 J1-1 (BUSY, 本体 pin1) |
| `IM_RESET` | U1 D3/A3 (GPIO29) — U2 J1-10 (RESET, 本体 pin19) |
| `IM_RXD` | U1 D6/TX (GPIO0) — U2 J2-3 (RxD, 本体 pin6) |
| `IM_TXD` | U1 D7/RX (GPIO1) — U2 J1-4 (TxD, 本体 pin7) |

**未接続**（オープンのまま）:

- U1: D4(GPIO6), D5(GPIO7), D8(GPIO2), D9(GPIO4), D10(GPIO3)
- U2: J1-8 (STATUS), J2-8 (REG), IO8〜IO10 ほか上記以外すべて
  - **IO8〜IO10 は必ずオープンのままにすること**。電源投入時にオープン／L でないと
    データモードで起動しない
- SW1 と STATUS LED は Rev.3 で廃止（設定/ペアリングは XIAO の BOOTSEL、
  状態表示は XIAO オンボードのカラー LED を使うため）

## レイアウト制約

ここが基板の出来を分ける。ファームでは救えない部分。

### 1. アンテナのキープアウト（最優先）

IM920sL はワイヤーアンテナ。**アンテナの周囲と真下にはベタ GND・配線・金属部品を置かない**。
基板の端に寄せ、できればアンテナ部分を基板の外へ出す。飛距離はこのプロジェクトの目的そのもので、
ここを妥協すると数十 m 単位で損をする。

### 2. USB の差動ペア D+/D−（送信機のみ）

- **できるだけ短く**、2 本を**等長・等間隔**で並走させる。間にベタや他の信号を挟まない
- R1/R2（22Ω）は **XIAO 側に寄せて**置く
- PIO-USB はソフトウェアでビットを叩いており、タイミング余裕が少ない
  （CPU 120MHz では列挙に失敗し、240MHz が必要だった）。配線が悪いと同じように不安定になる
- ビアは避ける。やむを得ない場合は 2 本とも同じ数だけ通す

### 3. 電源

- C3（0.1µF）を U2 の VCC ピン**直近**に、C2（10µF）をその外側に置く
- C1（47µF）は USB-A コネクタの VBUS 直近（ゲームパッド挿抜時の突入電流対策）
- IM920sL は送信時 27mA typ.。3.3V は XIAO のレギュレータから取る
  （資料に「電源ノイズは受信感度の低下や動作不安定の原因」とあるので、
  スイッチング電源から直接取らない）

### 4. その他

- 両面ベタ GND、ビアで縫う。ただしアンテナ下は除く
- XIAO はソケット実装を推奨（BOOTSEL と RESET ボタン、USB-C コネクタに手が届くこと）
- USB-A コネクタは抜き挿しの力がかかるので、固定用のパッドかネジ穴を設ける
- 送信機はモバイルバッテリー駆動。実測の消費電流は約 60mA

## 確認事項

- **IM920sL-ADP の J1/J2 の間隔**は製品資料の外形寸法図（外形 30.0 × 40.0mm、
  J1/J2 は 2.54mm×9 = 22.86mm）を実測で確認してからフットプリントを作ること
- USB-A レセプタクルは選定品によりフットプリントが違う
